Straight horizontal/vertical bar with optional rounded caps, inner keyline, cross dividers and a bottom-right label — header rules, thin side arms, spacer segments.
```jsx
<Bar thickness={24} caps="end" color="tan" keyline label="47-2201" />
<Bar orientation="vertical" length={300} thickness={30} color="tan" dividers={[0.85, 0.88]} />
```
- `length="flex"` grows to fill a flex row. `mode`: color | mono | outline.
